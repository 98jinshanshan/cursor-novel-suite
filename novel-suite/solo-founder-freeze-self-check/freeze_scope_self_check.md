# 冻结范围自查（个人开发者）

## 性质

这是**个人开发者冻结自查**，不是团队会议决议。无多人签字、无会议纪要伪造。

## 自查项

| 项 | 期望 |
| --- | --- |
| 仓库可作为本地 demo 冻结候选继续沉淀 | 负责人自行确认 |
| `freeze_candidate_only` | `true` — 仅候选冻结，非商业发布冻结 |
| 入口与能力范围可理解 | O1 已确认 |
| 商业 blocked 边界清晰 | 保持 `verdict=blocked` |

## 允许继续

- 本地 demo
- 文档完善
- PromptPack 优化
- 多 IDE dry-run

## 不允许

- 将自查等同于“批准发布”
- 创建 tag/zip/release
- 对外收费或公开发布
