# 禁止范围（个人开发者阶段）

无论 O2/O3 自查是否完成，以下行为**禁止**：

| 禁止项 | 说明 |
| --- | --- |
| `commercial_release_allowed=true` | 不得修改 |
| `verdict=approved` 或任何发布通过 | 不得修改 |
| tag / zip / release | 不得创建 |
| 对外销售、上传、发布 | 不得执行 |
| 法律宣称 | 不得声称已律师审核、已版权安全、已商业可用 |
| Blocker 关闭 | 不得自动关闭 B01–B04 |
| B05 升级 | 不得将 `resolved-demo-only` 升级为商业权利已批准 |
| 伪造记录 | 不得伪造会议决议或律师意见 |

Agent 不得代填 O2/O3 真实会议记录或法律结论。
