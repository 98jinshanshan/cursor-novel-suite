# Triage 规则（不自动应用）

## 优先级定义

| 级别 | 定义 | 示例 |
| --- | --- | --- |
| P0 | 阻断试跑或误导商业/法律边界 | 误以为可发布；validate 全面失败 |
| P1 | 显著影响 15 分钟 demo 或 PP-001 首跑 | 入口找不到；PP-001 输入不明 |
| P2 | 可绕过但增加摩擦 | 文档跳转冗余；某 IDE 需额外说明 |
| P3 | 改进项/锦上添花 | 文案润色；示例补充 |

## 处理原则

1. **不**自动应用任何 backlog 项到代码或 PromptPack
2. P0/P1 进入 R2 修订方案候选；须人工确认
3. 同一反馈可映射多分类，但须选一个主分类
4. `backlog_auto_applied=false` 直至 R 阶段显式决策

## 与 Q1/Q2 关系

- Q1 试跑记录可产生 BL-ENTRY、BL-CMD、BL-BOUNDARY
- Q2 卡点记录可产生 BL-PP、BL-DOC
- Q3 统一归类，供 R3 demo 迭代候选讨论
