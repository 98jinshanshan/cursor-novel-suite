# 商业发布仍 Blocked（P1 边界）

```yaml
commercial_release_allowed: false
verdict: blocked
demo_type: local_readonly_dry_run
```

## 本 demo 允许

- 阅读 `novel-suite/` 文档与 PromptPack
- 运行 `validate` / `list` / `read` 类 CLI
- 本地笔记填写 dry-run 反馈
- PromptPack 文档级试跑（不执行真实生成管线）

## 本 demo 禁止

- 修改 `commercial_release_allowed=true` 或 `verdict=approved`
- 创建 tag / zip / release
- 对外销售、上传、发布
- 声称已律师审核、已版权安全、已商业可用
- 关闭 B01–B04；升级 B05 为商业权利已批准
- 执行真实 adapter、FFmpeg、TTS、图像、视频合成
- 读取 `G:\SOLO小说项目` 或 `G:\Reasonix\SOLO小说视频项目`

## 关联门禁

- `novel-suite/commercial-release-candidate/` — 商业发布候选（仍 blocked）
- `novel-suite/solo-founder-release-blocked-declaration/` — 个人开发者合并声明

完成 15 分钟 demo **不等于** 批准商业发布。
