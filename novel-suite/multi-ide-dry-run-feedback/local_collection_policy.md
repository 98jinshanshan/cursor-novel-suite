# 本地收集策略

## 原则

反馈**只保存在用户本地**，不进入任何自动管道。

## 允许

- 用户在本机 Markdown/笔记应用填写 `feedback_template.md` 副本
- 用户自愿复制**脱敏**摘要到聊天或授权目录
- Cursor/Qoder 等 Agent 在用户明确要求时，读取**用户粘贴**的反馈文本

## 禁止

- Agent 自动扫描用户私密项目目录收集反馈
- 将反馈写入未授权云端或第三方 telemetry
- 未经用户粘贴即声称「已承接试用反馈」

## 承接路径（后续 Q 阶段）

用户完成试跑后，若需项目内承接：

1. 脱敏检查（无 PII、无第三方版权正文）
2. 用户明确授权范围
3. 粘贴至约定目录（由 Q1/Q3 提示词定义）

当前 P 阶段**不**创建承接目录或自动 ingest。
