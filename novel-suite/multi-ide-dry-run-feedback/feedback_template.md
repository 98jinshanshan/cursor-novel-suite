# Dry-Run 反馈模板（统一格式）

复制本模板到本地笔记填写。仅当用户**手动粘贴**授权后，方可进入 Q1/Q3 承接。

```markdown
# Novel Suite Dry-Run Feedback

## 元数据
- 日期：YYYY-MM-DD
- IDE：（cursor / codex / trae_cn / qoder / openclaw / generic_agent）
- 任务：（如 P1-15min-demo / PP-001-first-run / PP-003-spec-only）
- 耗时（分钟）：

## 入口与理解
- 产品入口是否清楚：（是/部分/否 — 说明）
- 是否看到商业 blocked 提醒：（是/否 — 在哪里看到）
- PP-001 是否被识别为新手起点：（是/否）

## 卡点
1.
2.
3.

## 建议
1.
2.

## 边界自查
- external_call_performed：（false — 若 true 请说明，通常不应发生）
- telemetry_collected：（false）
- private_project_read：（false）
- commercial_release_allowed 理解：（应为 false / blocked）

## 可选 Trace 引用
- 本地笔记路径：（仅路径，勿粘贴私密正文）
- 相关 validate 命令输出：（可粘贴 JSON 摘要）

## 提交方式
- 保存在本地，不自动上传
- 需要承接时，由用户复制脱敏版本到授权目录
```
