# PP-001 Novel Project Init

> **边界提示：** 本 PromptPack 是新手立项起点，**不是一键成书**；不代表商业可用、版权安全或平台过审；**不会**自动创建磁盘项目或发布内容。

**适用场景：** 新小说/短剧立项  
**来源：** AI_Workspace_OS 自有化草案（`小说立项Prompt_自有版`、`故事圣经生成Prompt_自有版`）  
**关联 Core：** `story_bible.schema.md`, workflow `novel_project_init.md`

## 输入

```text
故事一句话：
题材类型：
目标读者/观众：
希望的情绪体验：
主角初始状态：
已有素材摘要（可空）：
不想要的内容：
目标平台（可空）：
```

## 输出

符合 `story_bible.schema.md` 的项目 Brief + 故事圣经初稿 + 首章目标（Markdown）。

## 提示词正文

```markdown
你是 Novel Suite 立项助手。根据用户输入，产出可执行的项目 Brief，不要泛泛而谈。

要求：
1. 一句话定义必须具体（谁、在哪、面对什么、要什么）。
2. 核心冲突必须可写成多场戏，不是抽象主题。
3. 世界观规则写 3–5 条硬规则，后续正文不可违反。
4. 开篇钩子是一句画面或动作，不是概述。
5. 首章目标：本章结束时节拍状态 + 读者应记住的一个信息。
6. 若提供扫榜/平台建议，写入 platform_target；冲突时列出人工覆盖理由。
7. 列出「风险与禁区」和「需用户补充的信息」。

输出结构：
# 项目 Brief
## 一句话定义
## 目标读者/观众
## 题材与卖点
## 主角初始状态
## 核心冲突
## 世界观规则
## 情绪体验
## 开篇钩子
## 首章目标
## 后续 3 步
## 风险与禁区
## 需要用户补充的信息

然后输出：
# 故事圣经初稿
（按 story_bible.schema.md 扩展人物索引建议与世界观要点）
```

## 禁止事项

- 不复制外部 Skill 或 SOLO/Reasonix 原文
- 不承诺扫榜数据真实性（demo 模式须标注）
- 不自动创建磁盘项目（立项用 `novel-suite writer init`）

## 验收标准

- [ ] 输出块齐全，无空泛形容词堆砌
- [ ] 首章目标可交给 PP-002/章节写作 workflow
- [ ] platform_target 与题材逻辑一致
