# 试跑结果摘要模板（承接用）

用户完成试跑并脱敏后，可生成此摘要供 R1 只读承接。

```markdown
# Solo Demo Trial Summary

- trial_executed: true（仅用户确认后填写）
- ide:
- completed_15min_route: true/false/partial
- entry_clear: yes/partial/no
- top_blockers: （最多 3 条）
- external_call_performed: false
- blocked_reminder_seen: yes/no
- backlog_candidates: （可选，指向 Q3 分类）
```

**注意：** 本文件为模板；`trial_executed=false` 直至用户真实完成试跑。
