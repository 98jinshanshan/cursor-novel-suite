# 中文小说正文排版规范（叙事层）

> **依据：** 出版/Word 惯例（段首缩进 2 字符）、GB/T 15834—2011 标点、网文平台常见正文形态。  
> **与文件层分离：** `.md` 仅作载体；**正文不得写成 README/技术文档式顶格块**。

## 1. 两层结构

| 层 | 内容 | 是否顶格 |
| --- | --- | --- |
| **文件层**（工具用） | `# 第N章：标题`、首尾 `---`、`（第N章完）` | 顶格 |
| **叙事层**（读者正文） | 叙述、对话、心理活动 | **段首缩进 2 全角空格** |

Agent 写稿时：**文件层几行 + 叙事层连贯段落**；禁止把正文写成无缩进的 Markdown 说明文。

## 2. 段首缩进（必做）

- 叙事层**每一个自然段**段首加 **2 个全角空格**（`　　`，U+3000×2）。
- **禁止**用 4 个半角空格、Tab、或「无缩进顶格」代替。
- 段与段之间：**空一行**（源文件一行空白），不是 Markdown 列表。

**正确示例：**

```markdown
# 第1章：入府

---

　　永宁侯府的正门漆着朱红，门钉九行九列，铜环擦得锃亮。

　　沈知意站在门前，垂着眼帘，将那两扇大门的规制默默记下。

　　"沈姑娘，到了。"周婆子在垂花门前停住脚步，侧身让路，"太太在蕴秀阁等着呢。"

---

（第1章完）
```

**错误示例（Blocker）：**

```markdown
永宁侯府的正门漆着朱红……
（顶格、像代码/README）
```

## 3. 对话（GB/T 15834 + 网文惯例）

| 规则 | 要求 |
| --- | --- |
| 引号 | 中文双引号 `“` `”`，**禁止**英文 `"`、直角引号混用 |
| 成段 | 对话宜**独立成段**，段首仍 `　　` |
| 提示语 | 有说话动词多用冒号（例：段首缩进 + 柳氏道 + 全角引号对话）；动作衔接可用逗号 |
| 引号内标点 | 句号、问号等在引号**内**；引号外接后续叙述 |

**禁止：** 用 `()` `（）` 代替引号标示对话；禁止整段代码块包裹正文。

## 4. 标点与数字

- 中文叙述用**全角标点**（，。；：？！）。
- 书名、强调少用 Markdown `**粗体**`、`` `代码` ``；需要强调用描写，非排版标记。
- 一般语境下 1–10 可用汉字（「三日」）；确需阿拉伯数字时用半角数字（年份、统计）。

## 5. 场景切换

- **默认：** 空一行 + 下一段仍 `　　` 开头。
- **可选（voice-brief 写明）：** 一行居中分隔符（段首缩进 + `* * *` 或省略号行，一章 ≤2 次）。
- **禁止：** 章内 `##` 标题、`一/二/三` 小节、Markdown 列表 `-` 叙事。

## 6. `voice-brief.md` 字段

```markdown
| prose_layout | cn-fiction-indent |
| chapter_structure | continuous |
```

| `prose_layout` | 含义 |
| --- | --- |
| `cn-fiction-indent`（默认） | 叙事层段首 `　　` |
| `cn-fiction-no-indent` | 仅平台明确要求顶格时 |

## 7. 审稿 Blocker（novel-review ## Format）

- [ ] 叙事段 ≥95% 以 `　　` 开头（文件层与分隔符行除外）
- [ ] 无顶格大段正文（连续 2 段以上无缩进 → blocker）
- [ ] 对话为 `“”` 全角引号
- [ ] 无章内 `## 一/二/三`、无 Markdown 列表叙事

## 8. 旧稿批量修正

1. 保留文件层 `# 第N章`、`---`、`（第N章完）`
2. 删章内小节标题、列表符
3. 为每条叙事/对话段补 `　　`（已有缩进则统一为 2 全角空格）
4. 不改剧情字句，只改排版

## 9. 参考

- GB/T 15834—2011 标点符号用法  
- 出版排版：正文首行缩进 2 字符（Word「特殊格式→首行缩进→2 字符」）  
- 网文连载：顶格无缩进会降低可读性，与纸质版习惯不一致
