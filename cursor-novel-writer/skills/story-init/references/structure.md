# Story Project Structure

## story.md

Top-level bible read by all skills. Contains genre, premise, POV, tense, themes, style notes.

## Registries (_index.md)

Each domain maintains an index listing kebab-case IDs linking to detail files.

## Identifiers

Use kebab-case: `lin-mo`, `old-town`, `arc-main`.

## Cross-references

When A relates to B, update both files (bidirectional).
