# 平台 AI 写作合规参考（去 AI / 发表边界）

> **用途：** novel-review Phase 6–8 与 deai-checklist 的 **平台合规轨**。  
> **非法律意见**；规则随平台更新，发书前请阅最新官方公告。  
> **篇幅/字数口径：** [PLATFORM-LENGTH-AND-NORMS.md](../../../../docs/standards/PLATFORM-LENGTH-AND-NORMS.md)（章均 CJK vs 后台日更额度，勿混用「4000+」）

## 1. 共性原则（2025–2026 行业动向）

- **正文原创**：情节、场景、人物塑造须以作者创作为主；纯 AI 生成正文在各头部平台均高风险。  
- **反批量**：单日多本、高度同质化、缺乏可读性 → 限流/拒签/下架（番茄等多次公告）。  
- **反洗稿**：16 家平台《网络文学行业反洗稿自律公约》—— AI 洗稿、拼凑与抄袭同级风险。  
- **检测维度**（知网等 AIGC 检测常见）：困惑度、句式规整度、AI 高频词密度、跨段风格一致性。

## 2. 平台差异（写作时对照 `canon/voice-brief.md` → platform_target）

| platform_target | 允许 AI 辅助（参考公开规则） | 红线（勿碰） |
| --- | --- | --- |
| **番茄小说** | 大纲梳理、逻辑自查（非替代正文） | 批量 AI 水文、单日多本量产、洗稿 |
| **晋江文学城** | **文字型**：校对；**创意型**：极简粗纲（无具体情节） | AI 写情节/场景/人物；超范围辅助可锁章/禁榜 |
| **起点中文网 / 阅文** | 辅助工具需符合平台与用户协议；AI 生成正文可被屏蔽/撤榜 | 未披露或违规 AI 署名内容 |
| **通用** | 设定整理、伏笔表、自检清单 | 整章无人工润色的模板化输出 |

## 3. 本工具链合规用法

1. **Agent 产出 = 草稿**：须经 Phase 6–8 人工向验证 + de-AI + 再验证。  
2. **快照与 review 留痕**：`reviews/`、`canon/snapshots/` 表明修订过程（非发表稿）。  
3. **修订稿隔离**：验证阶段改稿在 `chapters/.drafts/`，通过后 promote，避免污染已定稿。  
4. **platform_target** 写入 `canon/project.json` 与 voice-brief，Sable 阶段必查本节。

## 4. 合规自检（写入 reviews/chNN-review.md）

```markdown
## Platform
- [ ] platform_target 红线未触犯
- [ ] 无批量模板化段落在全章重复
- [ ] 对话/细节具本书特有性（非通用 AI 例句）
```
